# Macでの初回設定

このフォルダは管理者専用です。Googleのパスワードや秘密キーは含みませんが、利用者と接続先の設定があるため、スタッフへの配布には使わないでください。

1. ZIPを展開し「816自動設定.command」をダブルクリックします。
2. ターミナルに表示された内容を確認し、Enterを押します。Google公式ツールの準備に数分かかります。
3. ブラウザーが開いたら、元帳を所有する木元さんのGoogleアカウントを選んで許可します。確認コードやパスワードをチャットへ送る必要はありません。
4. Googleの「Apps Script API」を有効にする画面が開いた場合は、有効にしてから同じファイルを開き直してください。
5. 公開された入力サイトが開きます。Googleの初回承認とメールの6桁コードでログインし、元帳の最終記入日・残高・入力開始日を確認して運用を開始します。

初回の管理者ログイン時に元帳の「リンクを知っている全員」等の一般公開を解除します。個別に指定した共有先は残します。保存用タブ4枚と非公開のレシート用フォルダを作成します。既存の明細を上書きしません。福井さんと木元さんだけがメール確認後に利用できます。

URLはターミナルと、Macの「ライブラリ/Application Support/WUTO-WURK-Cashbook/専用URL.txt」に記録されます。スタッフにはこのURLだけを共有してください。スタッフはGoogleへのログインと、本人の登録メールに届く6桁コードで利用します。Googleからアプリの警告や権限エラーが出た場合は、そのまま進めず表示内容を確認してください。

## 初回承認で止まる場合

Googleが実行権限の承認を求めたままサイトが開かない場合は、Apps Scriptの新しい「816 現金出納帳 入力専用」プロジェクトを開き、関数 `ownerSetup_` を1回実行して権限を承認します。コードの貼り付けは不要です。完了後、発行されたURLを開き直してください。元帳の残高確認はサイト側で別途行います。

Macが実行ファイルを開けないと表示した場合は、セキュリティ機能を無効にせず、そのメッセージを共有してください。

## 日々の入力と修正

営業日・担当者を確認して売上、決済、仕入、入出金と実際の現金を入力し、確認画面で登録します。「登録が完了しました」と表示されたときだけ保存済みです。現金以外の仕入支払は現金残高を減らしません。銀行への預入は現金出金、金券販売は現金入金、金券利用は売上の決済内訳です。

修正は同じ営業日を選んで行います。他の人が更新していたら再読み込みして確認します。通信エラー時は入力を残し、同じ内容で再送できます。共用端末では必ずログアウトしてください。

元帳は正本を維持します。アプリ登録済みの範囲をシートから手修正すると安全のため次の保存を止めます。元帳の直接入力とアプリを同じ営業日に併用しないでください。既存記入日以前は新規登録できません。

## 現時点の検証範囲

設定プログラムのテストと入力画面の動作確認は済んでいます。お使いのMacでのGoogle認証、本物のGoogleへの公開、実メール配信、正式元帳への保存は、このファイルを実行するまで未確認です。最初は管理者がURLと残高を確認してください。正式元帳へテストデータを入れないでください。

認証情報はMac内の上記専用フォルダに保存されます。このフォルダを他人に渡さないでください。停止・権限解除はGoogleアカウントの外部アプリ接続とApps Scriptのデプロイ管理から行えます。Googleの無料枠やメール送信件数制限が適用されます。
