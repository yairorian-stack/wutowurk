E2E はデスクトップとスマートフォンサイズの Chromium で、目標の作成・編集・再読み込み後の保存、成果検索、変更前後の履歴、複製、二重登録拒否、未完了繰越、3件上限、担当者・状況・期限の絞り込み、過去週検索、ビジョン切替・編集保存、資料閲覧、ダイアログのフォーカス・Escape を検証。幅320px・768pxで全5画面に横方向のはみ出しがないことも確認。

4権限の確認はサンプルのUI表示と操作範囲を対象としている。サーバー認証・他店舗APIへの不正アクセス防止・本番データ保護の検証ではない。iPhoneサイズのテストも Chromium であり、実機Safariの検証は本番準備時に行う。

売上・日報・出納帳について、日報の二重登録防止、訂正・古い版の拒否、円と分の整数検証、24時間超の労働時間、現金売上の自動反映、現金以外の売上の除外、銀行入金・繰越・残高・照合、理由付き取消、店舗分離、同期間比較、未入力と0の区別、前年0・うるう年、CSVの引用・式無害化を検証。E2Eは本番用ビルドをローカル起動して実施した。

画面キャプチャは `test-results/home-desktop.png` と `test-results/home-mobile.png` に生成（Git管理対象外）。Next.js 16.4.2 / React 19.3.1 / Node.js 24.19.0。
