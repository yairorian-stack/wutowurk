# 店舗シフトと提供売上の読み込み

## シフト

`/shifts`（GitHub Pagesでは `#/shifts`）で店舗別の月間カレンダー、日別の時間帯、人数、予定労働時間を表示します。未登録日は休業・欠員・0時間と断定しません。サンプルは明示的に開いた場合だけ表示します。

CSVはUTF-8、見出し `店舗,日付,表示名,開始,終了,休憩分`。店舗は `本店` / `羽ノ浦店` または既存ID `honten` / `816`、日付は `YYYY-MM-DD`、時刻は `HH:MM`、翌日終了は `25:00` の形式です。最大2,000勤務、1MB。休憩を除いた予定時間を開始日へ集計します。バーは休憩時刻が不明のため休憩を含んだ開始〜終了の範囲です。日付・店舗をまたぐ同一表示名の勤務重複を拒否します。実労働時間・売上人時には反映しません。

読み込みは画面上の全件置換で、画面離脱・再読み込みで消えます。表示名は識別名を推奨します。勤務予定はストレージ、URL、ログ、サーバー、公開HTMLに保存しません。ブラウザーの役割切替はプレビューであり、認証ではありません。

### Airシフト連携の状況と必要条件

指定URL `https://airshift.jp/sft/monthlyshift` への外部リンクを設置しています。これは同期ではありません。2026-10-25の調査では開発環境のHTTPプロキシがCONNECTを403で拒否し、Airシフトへ到達できませんでした。Airシフト側のログイン画面、エクスポート、API提供の有無・仕様・契約条件は確認できていません。専用コネクター・認証情報もありません。

自動取得は**未実装・未接続**です。定期実行サーバーのない現在のGitHub Pagesで、外部URLへのリンクだけから非公開の最新シフトを取得することはできません。

実装再開時は、公式に利用できる連携方式（API等）の有無を確認し、許可された店舗アカウントを使って、非公開のサーバー側接続と同期処理を追加します。アカウント接続先、閲覧権限、保存先、費用は依頼者の確認が必要です。パスワードや認証Cookieを公開コードに含めません。

データ境界は `Shift`（店舗ID、開始日、表示名、開始分、終了分、休憩分）です。将来の連携アダプターで、公式ソースの店舗対応表・安定した勤務ID・最終更新時刻・削除情報を検証し、全件取得の成功後にのみスナップショットを更新します。接続失敗時は古いデータの取得日時を表示し、「最新」と表示しません。現段階で未確認のAPIや画面スクレイピングを作りません。

本店は依頼者回答により紙・その他で管理しています。「紙のシフトを入力する」から日付・表示名・開始・終了・休憩を転記できます。追加した予定はCSVで保存し、次回読み込み直せます。入力・読込は画面内だけで、自動保存・スタッフ間共有はしません。架空サンプルを表示中に手入力すると、サンプルを閉じて入力した予定だけに切り替えます。

羽ノ浦店の代替は上記共通CSVの読み込みです。Airシフト固有のCSVにそのまま対応するとの保証はありません。実ファイルの列と対応関係を確認して変換する必要があります。

## 提供された日別売上

`/daily` の「提供データの売上記録」にJSONを読み込み、日別売上・元表の月累計・元表の昨年対比を表示します。**サンプル財務データとは別管理**です。「この端末に保存」を押した場合だけ `wuto-wurk-imported-sales-v1` へ保存します。別ファイルは画面上の全件置換で、保存すると保存済みデータも置換します。バックアップを保管してください。スタッフ間・端末間の同期やサーバー保存はありません。

形式：`{ version: 1, source: string, asOf: YYYY-MM-DD, rows: [{ date, honten: {sales, cumulative, reportedYoy}, "816": {...} }] }`。金額は0以上の整数円、未入力は `null`。売上0円と空欄を区別します。同じ日付の重複、不正日付、月累計と日別合計の不一致、基準日後の非null売上は取込前に全件検証し、不正な場合は現在の記録を変更しません。

月累計は記入済み日別売上の合計で、空欄を休業日として補完しません。`reportedYoy` は提供された累計前年比です。丸められた割合から前年金額を逆算したり、両店舗の前年比を平均したりしません。基準日後の空欄行・累計・前年比は元データとして保持しますが、実績画面の対象から除外します。

現金・キャッシュレス内訳、労働時間がないため、既存日報や現金出納帳へ転記しません。出納帳の入金を捏造せず、人時売上高は未取込のままです。元の `wuto-wurk-finance-demo-v1` と `wuto-wurk-prototype-v1` は保持します。

### 私的な確認用ファイル

`npm run build:pages` の後、`node scripts/prepare-daily-sales-preview.mjs <private-json> <private-html>` で、実売上を含むHTMLをリポジトリ外にのみ生成できます。公開ビルドは実売上を含みません。取り込みは権限管理された共有DBへの登録ではありません。現在のサイトはログイン不要のため、実金額をPagesへ掲載する前に依頼者の明確な承認を得てください。
