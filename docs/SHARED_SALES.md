# 提供済み売上の非公開共有確認版

対象は依頼者提供の2026年8月1日〜10月24日、本店・羽ノ浦店の85日/170店舗日です。元の表の10月25〜31日は売上空欄で、基準日後のため取り込みません。日付の曜日も2026年の暦と対応します。金額と私的な出典はGitに置きません。

本店・羽ノ浦店それぞれの月累計を日別売上の和と照合し、以前に確認済みの10月22日時点の累計とも一致することを非公開の検証で確認しています。空欄は0円や休業と断定せずnullで保持します。昨年対比は提供表の累計比率をそのまま表示し、全社の比率や昨年実額を推定しません。現金/キャッシュレス内訳・労働時間・客数・出納帳開始残高/入出金は未提供です。これらの数字は売上から作らず、人時売上・現金残高は未照合のままです。

追加マイグレーション `202610260003_shared_sales.sql` は、取込単位と店舗別日別売上の読取専用テーブル、RLSを作ります。実データを含む登録SQLはリポジトリ外にのみ準備しています。OTP追加設定と合わせた1回のトランザクションも用意しています。まだ実プロジェクトへ登録したとは扱いません。

全社・システム管理者は両店、店舗管理者は所属店だけを読めます。一般スタッフ・未承認・停止済み・未登録・未認証には売上を渡しません。SELECTは本人の認証キーで行い、service_roleキーで全店データを取ってブラウザーで隠す実装にはしません。ログイン前やPagesの公開HTMLに実数を含めません。認証済みの/dailyでDBから取得し、RLSで許された行だけを表示モデルへ渡します。ブラウザーの保存データや架空のサンプルと合算せず、公開済みのスナップショットがある場合は実績専用の読取画面にします。

これは提供時点の履歴確認版です。元のスプレッドシートの自動同期、以後の日付の実績、日報/出納帳への共有書込は含みません。入力ファイルを再登録するときは重複や既存実績の上書きを確認し、所有者が私的なバックアップを取得してから別の取込として扱います。通常のログイン利用者には実績テーブルの書込権限を付与しません。
