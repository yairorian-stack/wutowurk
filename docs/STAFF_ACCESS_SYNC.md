# スタッフ権限台帳の同期

Googleスプレッドシートに標準タブ名 `スタッフ権限` を作り、A1から次の7列を貼り付けます。実在メールはこの非公開シートだけに入力し、Gitやチャットへ貼りません。

```tsv
メールアドレス	氏名	役職	所属店舗	権限	閲覧範囲	有効/無効
owner@example.invalid	架空 管理者	総合責任者	両店舗	全社管理者	両店舗	有効
honten@example.invalid	架空 本店スタッフ	社員	本店	一般スタッフ	本店のみ	有効
hanoura@example.invalid	架空 羽ノ浦店長	店長業務	羽ノ浦店	店舗管理者	羽ノ浦店のみ	無効
```

## 入力できる値

- 役職: `総合責任者`、`店長業務`、`社員`、`パートアルバイト`、`他メンバー`
- 権限: `一般スタッフ`、`店舗管理者`、`全社管理者`、`システム管理者`
- 所属店舗: 店舗権限は `本店` または `羽ノ浦店`。全社・システム管理者は `両店舗`
- 閲覧範囲: `本店のみ`、`羽ノ浦店のみ`、`両店舗`
- 有効/無効: `有効` または `無効`

メールは空白除去・小文字化後に重複検査します。見出し違い、不正なメール、未知の値、所属店舗と閲覧範囲の不一致、重複、または有効な全社/システム管理者が1人もいない台帳は全件反映されません。

## 同期設定

`production-data-sync` 環境の既存 `SHEETS_SYNC_CONFIG` に、[`sheets-sync.example.json`](sheets-sync.example.json) と同じ `staffAccess` を追加します。既存の `sales` と `cashSources` は変更・削除しません。`spreadsheetId`、`sheetId` は非公開シートの値へ置き換え、既存サービスアカウントへ閲覧権限だけを付与します。

`staffAccess` が無い間も売上・出納帳の同期は継続し、スタッフ権限だけ未構成としてログへ記録します。手動実行の `dry_run=true` では台帳を検証し、有効/無効件数だけを表示してDBを変更しません。

本番同期後はSupabaseが認可の正本です。未登録・無効ユーザーは拒否され、一般スタッフと店舗管理者は所属店舗だけ、全社・システム管理者は両店舗を閲覧できます。店長日報の登録は引き続き店舗管理者以上だけです。
